Section 4 — File Upload Architecture

Architektúra uploadu súborov

Systém máš — treba opraviť dva reálne problémy a dať mu škálu.

Jadro opravy: client-direct upload, nie cez funkciu To je to, čo obíde limit 4,5 MB. Prehliadač posiela súbor priamo do Blob storage; funkcia vidí len malé JSON.

Storage → Vercel Blob

Si na Verceli, takže Blob je najmenší odpor (S3 + presigned URL je alternatíva mimo Vercel). Postgres drží len metadáta: okruh_files nech má blob_url + content_hash, stĺpec data bytea odstráň. Tradeoff: druhá služba a treba mazať blob pri zmazaní riadku — ale riadky ostanú malé a rýchle.

Cesta uploadu

  1. Klient si vyžiada upload token: POST /api/okruhy/[id]/files/upload-url (funkcia autorizuje používateľa/okruh).
  2. Prehliadač nahráva priamo do Blob — obíde limit tela; odtiaľto sú aj reálne progress eventy.
  3. Po dokončení klient zapíše metadáta: POST /api/okruhy/[id]/files s { blob_url, filename, mimetype, size_bytes, content_hash }.

@vercel/blob handleUpload spraví krok 1 a 3 za teba.

Limit = 20 MB

Vynútený na 3 miestach: klient (okamžitá spätná väzba), token handler (autorizácia veľkosti), DB check constraint ako poistka. Dnes je 30 MB a kontrola až po prijatí bajtov.

Drag&drop + progres

Drag&drop už máš. Pridaj reálny progress bar z Blob onUploadProgress, frontu viacerých súborov a stav na súbor (queued → % → done → error+retry).

Validácia

Drž allowlist ALLOWED_TYPES. Pridaj klientskú kontrolu prípony+MIME pred tokenom a znova v handleri. Jasná SK chybová hláška, nie generický toast.

Náhľady

Obrázky thumbnail priamo z blob_url; PDF prvá strana cez <embed>/react-pdf alebo ikona + „Otvoriť"; Office ikona + stiahnuť. Lazy-load náhľadov.

Ošetrenie chýb

Výpadok počas uploadu → Retry; vypršaný token → znova; zlyhaný zápis metadát po úspešnom blobe → reconcile (retry riadok alebo zmaž osirený blob). Inline stavy v riadku, nie len toast.

Prílohy pre poznámky

Zovšeobecni pipeline: jedna tabuľka attachments(parent_type, parent_id, …) namiesto okruh_files, použiteľná v okruhu aj v editore. Tradeoff: malá migrácia existujúcich riadkov, jedna cesta v kóde.
