Section 7 — Technical Changes

Technické zmeny

Predpokladaný stack je Tailwind; realita sú inline štýly. Nemigruj naraz.

Otázka Tailwindu

Dve cesty: (a) drž tokeny a vytiahni opakované inline vzory do komponentov (Card, Input, EmptyState, Stack) — nižšie riziko, zachová vzhľad; (b) Tailwind prírastkovo len pre nové plochy (editor, hľadanie, bottom-nav). Odporúčam (a) teraz, (b) zváž až pri druhom vývojárovi.

Storage

Vercel Blob, client-direct upload, v Postgrese len metadáta (sekcia 4). Najväčšia tech zmena a opravuje reálny prod bug.

Zmeny v DB (aditívne)

  • okruhy: category, icon, color, metadata jsonb, archived_at.
  • materials: status (draft/published/archived), content_hash, archived_at. content už je.
  • Nové tags + note_tags; favorites (alebo booleany).
  • okruh_files → attachments(parent_type, parent_id, blob_url, content_hash, …).
  • Indexy: GIN tsvector na obsah; btree na (subject_id, archived_at) a (okruh_id).

Výkon

Landing a read-only zoznamy (subjects, materials) na Server Components — preč s waterfallom a bliknutím. Už hotové: de-dup /api/user/subjects cez context, Promise.all trojice dotazov, atomický PUT. Ďalej: cacheuj takmer statické čítania (subjects, resources) cez revalidate namiesto force-dynamic všade.

Caching

Statický katalóg cez ISR; per-user dáta dynamické, ale fetchnuté raz a zdieľané cez context. Pri vyhľadávaní debounce + cache posledných dopytov.

Stav

Netreba Redux/Zustand. React Context (session) + stav vo URL (filtre/hľadanie/taby) stačí. SWR/React Query pridaj len pre editor a hľadanie kvôli optimistickým updatom.

API

Drž REST-ish route handlery: /api/notes, /api/attachments, /api/okruhy, /api/search. Jednotné odpovede {data}/{error}, tenký requireSession() wrapper, validácia vstupov (zod).

Bezpečnosť

Preč od nesoleného SHA-256, odstráň hardcoded JWT_SECRET fallback, zmeň zdieľané heslo123 účty a vyhoď ich z README.
