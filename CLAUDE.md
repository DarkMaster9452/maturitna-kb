# MaturitaKB — pracovné pokyny

## Dizajn UI — DÔLEŽITÁ preferencia autora

- **NIKDY nepoužívaj „základné"/predvolené vizuálne vzory od modelu.** Konkrétne zakázané:
  - fialovo/indigové gradienty (`grad-brand`, `#6366f1`→`#8b5cf6` a pod.),
  - gradientové tlačidlá, gradientové nadpisy (gradient text),
  - glassmorphism / „aurora" rozmazané bloby,
  - pôvodná indigo/violet paleta.
- Autor **vždy** chce výrazne odlišný, **skutočne moderný, prehľadný a „napredujúci"** vzhľad.
  Pri každom redizajne zvoľ **nový, samostatný** dizajnový smer — nerecykluj predchádzajúci.
- Ak si nie si istý smerom, radšej sa krátko opýtaj, než použiješ generický default.

### Aktuálny smer: „Editorial / Ink"
- Monochromatická **paper/ink** paleta (near‑black text na teplom off‑white).
- **Vlasové (hairline) 1px okraje** namiesto ťažkých tieňov; ploché (flat) výplne.
- **Jeden striedmy akcent** (emerald) — použitý minimálne (aktívne stavy, pokrok, odkazy).
- Primárne tlačidlá = plná **ink** farba (čierna na svetlom / biela na tmavom), nie farba akcentu.
- Typografia: **Bricolage Grotesque** (display) + **Inter** (text) + **mono** popisky (eyebrow/labels).
- Svetlý aj tmavý režim + alternatívny akcent (SPSIT = modrá).
